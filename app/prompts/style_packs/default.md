# 기본 기출 스타일 (default)

특정 시험으로 식별되지 않은 카테고리의 일반 기출 양식.

## 시나리오 기반 출제 원칙 (최우선)

기출은 단순 개념 암기가 아닌, **가상 상황·인물·조직을 짧게라도 등장시켜 그 안의 부적합·누락·오류를 식별하는 형태** 를 지향합니다.
강의노트의 정의를 그대로 묻지 말고, 한두 줄짜리 가상 상황(가상 회사·팀·사건)을 stem 앞부분에 두고 그 안에서 옳고 그름을 가리도록 구성합니다.

- 예시: "○○팀이 다음과 같은 절차를 운영하고 있다. (...30~60자 가상 상황) 이 절차에서 가장 보완이 필요한 부분은?"

## 형식
- 5지선다 객관식이 기본. 문항 stem 은 60~140자 사이 중문/단락.
- 보기 5개의 길이는 비슷하게 맞춘다 (가장 긴 보기/가장 짧은 보기 비율 ≤ 2).
- 보기 시작은 ① ② ③ ④ ⑤ 가 아닌 단순 텍스트 — UI 가 번호를 자동 매김.
- 함정 보기는 표면상 그럴듯하되 SOURCE 와 한 항목이 충돌해야 한다.

## 지문 블록 가이드
- 평이한 단문형 위주. 지문 블록은 가급적 사용하지 않음 (passage=null).
- 사용 시 passage 200~400자, 후속 문항 2개 묶음.

## 어투
- 한국어 평서체. "옳은 것은?" / "옳지 않은 것은?" / "가장 적절한 것은?" 패턴.
- 부정형 질문에는 stem 끝에 "(틀린 것)" 등 명시.

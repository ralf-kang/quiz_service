# 정보보안기사 시험 범위

출처: 한국산업인력공단(Q-Net) https://www.q-net.or.kr/

## 필기 (5과목)

### 1. 시스템 보안
- 운영체제 보안: Linux/Windows 권한 모델
- 무결성 모델: BLP, Biba, Clark-Wilson
- 메모리·프로세스 보안
- 악성코드 분석

### 2. 네트워크 보안
- TCP/IP 프로토콜 분석
- 방화벽 / IDS / IPS
- ARP / DNS / DDoS / Spoofing 공격 및 방어
- VPN, IPsec, SSL/TLS

### 3. 애플리케이션 보안
- OWASP Top 10 (SQLi, XSS, CSRF, IDOR …)
- 세션·쿠키·인증 보안
- 웹 보안 헤더, CSP
- 모바일 앱 보안

### 4. 정보보안 일반
- 암호학: 대칭/비대칭, 해시, 디지털서명, 인증서, PKI
- 접근통제 모델: DAC/MAC/RBAC
- 위험관리·관리체계
- 보안 거버넌스

### 5. 정보보안 관리 및 법규
- 개인정보보호법, 정보통신망법
- ISMS, ISMS-P
- 전자서명법, 신용정보법

## 실기 (단답·약술·서술)
- 패킷·로그 분석
- 시나리오 기반 보안 사고 대응
- 시스템·네트워크·웹 취약점 진단 결과 해석

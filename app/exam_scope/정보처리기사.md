# 정보처리기사 시험 범위

출처: 한국산업인력공단(Q-Net) 공고 https://www.q-net.or.kr/

## 필기 (5과목)

### 1. 소프트웨어 설계
- 요구사항 확인: 요구사항 분석·정의서·검증
- 화면 설계: UI/UX 설계 원칙, 와이어프레임, 프로토타이핑
- 애플리케이션 설계: 객체지향 설계, GoF 디자인 패턴, 모듈화·결합도·응집도
- 인터페이스 설계: 시스템 인터페이스 요구사항, 데이터 명세

### 2. 소프트웨어 개발
- 데이터 입출력 구현: 자료구조(스택·큐·트리·그래프), 정렬·검색
- 통합 구현: 모듈 통합, 빌드, 형상관리(Git)
- 제품 소프트웨어 패키징: 패키징 도구, 매뉴얼·릴리스 노트
- 애플리케이션 테스트 관리: 테스트 케이스, 단위·통합·시스템 테스트, 성능 테스트
- 인터페이스 구현: REST/SOAP, 보안 통신

### 3. 데이터베이스 구축
- 논리 데이터베이스 설계: ER 모델, 정규화/이상현상
- 물리 데이터베이스 설계: 인덱스, 파티셔닝
- SQL 응용: DDL/DML/DCL, 조인, 집계, 서브쿼리
- 트랜잭션·동시성 제어: ACID, 락, 격리수준
- 백업·복구

### 4. 프로그래밍 언어 활용
- 서버 프로그램 구현: Java/Python/C# 등
- 프로그래밍 언어 기초: 변수·자료형·연산자·제어문
- 응용 SW 기초기술: 운영체제(프로세스·스레드·메모리·파일시스템), 네트워크(OSI 7계층)
- 알고리즘 시간/공간 복잡도(빅오)

### 5. 정보시스템 구축관리
- 소프트웨어 개발 방법론: 폭포수·반복적·애자일
- IT 프로젝트 정보시스템 구축관리
- 소프트웨어 개발 보안 구축: OWASP Top10, 시큐어 코딩
- 시스템 보안 구축: 인증·인가, 암호화, 해시, 디지털 서명, PKI

## 실기 (단답·약술 + 코드 작성)
- 위 5과목의 실무 적용. 코드 분석/작성, SQL 작성, 디자인 패턴 식별.
